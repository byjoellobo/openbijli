# Data licence

The compiled tariff data in this directory (`data/tariffs`, `data/national`, `data/solar`) is
licensed under the **Creative Commons Attribution 4.0 International** licence (CC BY 4.0):
https://creativecommons.org/licenses/by/4.0/

Attribute as: "OpenBijli contributors, tariff data (CC BY 4.0)".

The underlying tariff orders, regulations and gazettes are public documents of their
publishers; each value links to its source. Solar irradiance values are derived from the NASA
POWER Project (https://power.larc.nasa.gov/), which NASA makes freely available.

The data is provided as is. Always check a bill against the current order before acting on it.

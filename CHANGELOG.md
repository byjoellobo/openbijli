## [0.1.0] - 2026-11-03

The first public release.

### Added

#### Tariff data (`data/`, `@openbijli/data`)

- 9 tariff books for FY 2026-27 covering 25 utilities: Karnataka (MESCOM, BESCOM, HESCOM,
  GESCOM, CESC Mysore), Maharashtra (MSEDCL), Gujarat (DGVCL, MGVCL, PGVCL, UGVCL), Delhi
  (BRPL, BYPL, TPDDL), Uttar Pradesh (PVVNL, MVVNL, DVVNL, PuVVNL, KESCO), Tamil Nadu (TNPDCL),
  Kerala (KSEB), Telangana (TGSPDCL, TGNPDCL) and Rajasthan (JVVNL, AVVNL, JdVVNL).
- Each book records slabs, fixed charges, time-of-day rates, additional charges, government
  subsidies, rooftop solar regimes (net metering, net billing, gross metering), export rates,
  settlement and banking rules and consumer protections, with a citation, page number,
  verification level and list of known gaps. All books are marked `partial`.
- National parameters: PM Surya Ghar central financial assistance, MNRE benchmark installed
  cost, simulator assumptions and national consumer rights.
- NASA POWER 2001-2025 monthly irradiance for 30 reference locations.
- A zod schema with generated JSON Schemas for editors, a bundled typed catalog and lookup
  helpers (`getTariff`, `getUtilities`, `getSolarResourceForUtility` and more).

#### Bill engine and solar simulator (`@openbijli/engine`)

- `computeBill()` for one billing cycle: telescopic and whole-consumption slabs, fixed charges
  by load or consumption band with load rounding, time-of-day adjustments, per-kWh, percentage,
  flat and consumption-banded additional charges, solar charges per kW or per kWh, opt-in and
  automatic government subsidies (payable schedule and entitlement rules), and solar netting
  with banking and settlement. Every line is rounded to paise and carries citations,
  verification level and warnings.
- `simulateSolar()` for rooftop right-sizing: hourly generation shape from solar geometry,
  three household load profiles or a custom 24-hour profile, 25 years of billing cycles with and
  without solar, PM Surya Ghar subsidy, NPV, IRR, simple and discounted payback, and a
  plain-language rationale for the recommended size.
- `openbijli` CLI with `utilities`, `bill` and `solar` commands.

#### Evidence engine (`@openbijli/evidence`)

- Meter Sakshi log parser with strict validation and SHA-256 hash-chain verification that
  pinpoints the first edited record.
- Bill reconciliation with coverage-aware verdicts, prepaid deduction audit, outage and
  recharge-restoration analysis, and home no-load and reference-load meter tests.
- Self-contained HTML report (escaped values, restrictive Content-Security-Policy) and
  Markdown report.
- `meter-sakshi` CLI with `verify`, `report` and `simulate` commands.

#### Web app (`apps/web`)

- Four views: **Check a bill**, **Size rooftop solar**, **Dispute a bill** and **Tariff data**,
  all running in the browser with no network calls for user data.
- Itemised bill slip with numbered source links and verification marks, solar size chart and
  comparison table, dispute report builder with demo data, and a tariff browser that lists each
  book's rates, gaps and sources.
- Mobile layout with a sticky result bar, keyboard and screen-reader support, and a
  Content-Security-Policy on the built site.

#### Meter Sakshi hardware (`hardware/meter-sakshi`)

- ESP32 firmware (PlatformIO): debounced pulse counting from the meter's kWh LED, supply-loss
  detection, minute records stored on LittleFS, hash-chained CSV export with daily digests,
  NTP time with an optional DS3231 RTC, and no-load and reference-load test modes.
- Device web interface protected by a 6-12 digit PIN (salted and hashed, lockout after five
  wrong attempts), Host header checks against DNS rebinding, cross-site POST rejection and
  frame blocking. Setup access point with a random per-device password.
- Portable `sakshi_core` library with native unit tests that share test vectors with the
  TypeScript evidence engine.
- ESPHome variant for Home Assistant, parametric OpenSCAD sensor clip and electronics box,
  wiring, safety and legal notes, and a log format specification.

#### Tooling and automation

- Scripts to build and validate data, diff tariff books with bill impact, fingerprint source
  PDFs, fetch NASA POWER data, check the tariff season and generate a sample log.
- 93 unit tests (Vitest) with an 80% coverage threshold, and 28 Playwright browser tests of
  the production build on desktop and phone viewports, including an axe accessibility scan
  of every page.
- GitHub Actions for CI on Node 22 and 24 plus browser tests, CodeQL code scanning, firmware
  build and native tests, GitHub Pages deployment, tariff pull-request review with a
  bill-impact comment, and a twice-monthly tariff season checklist. Dependabot for npm and
  GitHub Actions.
- Releases with release-please: one lockstep SemVer version, `vX.Y.Z` tags, generated
  changelog, and GitHub Release assets (portable web app, data bundle, npm package tarballs,
  checksums) with signed build provenance. npm publishing via trusted publishing, off until
  enabled.
- Issue forms for bugs, feature requests, wrong numbers and new tariff orders; pull request
  templates; security policy, code of conduct, support guide and citation file.
